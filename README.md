# Student Result Calculator

A simple offline student result calculator. Open `index.html` directly in Chrome, Edge, Firefox, or another modern browser. No commands, installation, or internet connection are needed.

## Start using it (no commands)
1. Open this GitHub repository page.
2. Click the green **Code** button, then choose **Download ZIP**.
3. Open your computer's **Downloads** folder.
4. Right-click the ZIP file and choose **Extract All**.
5. Open the extracted **Student-Result-Calculator** folder.
6. Double-click **index.html**. The calculator opens in your browser.
7. If Windows asks which app to use, choose **Google Chrome** or **Microsoft Edge**.

## PDF download options
The browser creates the PDF using its built-in print-to-PDF feature. No extra software or internet connection is required.

1. **Current student's PDF:** Click **Download Current Result PDF** at the top. In the print window, choose **Save as PDF** as the destination/printer, then click **Save**.
2. **One saved student's PDF:** In Saved Student Records, click **Download PDF** next to that student. Choose **Save as PDF**, then **Save**.
3. **Class-wise PDF:** Select a class in the **Show Class** filter, then click **Download Class / All Results PDF**. Choose **Save as PDF**, then **Save**.
4. **All classes PDF:** Set **Show Class** to **All Classes**, then click **Download Class / All Results PDF**. Choose **Save as PDF**, then **Save**.

Tip: In the print window you can choose a folder and filename before saving. If the PDF window does not open, allow pop-ups for the page/browser.

## Features
- Seven default subjects and unlimited extra subjects.
- Change subject names and maximum marks independently.
- Save multiple students with class and roll number.
- Filter saved results by class.
- Automatic total, percentage, grade and pass/fail calculation.
- Print/PDF current result, one saved student's result, a selected class, or all classes.
- Export saved data as JSON.
- Records are stored in the same browser on the same device.

## Grade scale
A+: 90%+, A: 80–89.99%, B: 70–79.99%, C: 60–69.99%, D: 50–59.99%, E: 40–49.99%, F: below 40%.
